# Issue types and workflow

## Common issue types

| Type | Used for |
| --- | --- |
| Epic | A large goal made of many issues |
| Story | A feature from the user's point of view |
| Task | A piece of work that is not a user feature |
| Bug | Something that is broken |

## Workflow

Issues move through statuses, typically **To Do → In Progress → Done**. Teams can add steps such as *In Review* or *Testing* to match how they work.
