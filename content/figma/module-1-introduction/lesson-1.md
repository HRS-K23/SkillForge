# What is Figma?

Figma is a browser-based design tool for user interfaces. Designers, developers and product managers can open the same file at the same time.

## What you can do

- Design screens for websites and apps.
- Build reusable components and design systems.
- Connect screens into clickable prototypes.
- Leave comments directly on the design.

Figma runs in the browser, so there is nothing to install to get started.
