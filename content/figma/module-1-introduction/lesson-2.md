# Tour of the interface

- **Canvas** - the infinite area in the middle where you design.
- **Layers panel** (left) - every object in your file, in stacking order.
- **Toolbar** (top) - move, frame, shapes, pen, text and comment tools.
- **Properties panel** (right) - size, position, fill, stroke and effects for the selected object.

## Handy shortcuts

| Action | Shortcut |
| --- | --- |
| Frame tool | `F` |
| Rectangle | `R` |
| Text | `T` |
| Zoom to fit | `Shift + 1` |
