# What is Docker?

A **container** packages an application together with everything it needs to run: code, runtime, libraries and settings. The same container behaves the same on your laptop, a colleague's machine and a server.

## Containers vs virtual machines

| | Container | Virtual machine |
| --- | --- | --- |
| Shares the host kernel | Yes | No |
| Start-up time | Seconds | Minutes |
| Size | Megabytes | Gigabytes |

## Key words

- **Image** - a read-only template used to create containers.
- **Container** - a running instance of an image.
- **Registry** - a place to store and share images, such as Docker Hub.
