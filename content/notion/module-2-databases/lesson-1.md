# Creating a database

A database is a collection of pages that share **properties** such as a date, a status or a tag.

1. Type `/table` and choose **Table view** to create a new database.
2. Rename the columns. Each column is a property.
3. Add rows. Every row is a page you can open.

## Property types

Text, Number, Select, Multi-select, Date, Checkbox, URL and Person are the most common.
