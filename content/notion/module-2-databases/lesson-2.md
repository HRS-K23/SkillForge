# Views, filters and sorting

One database can be shown in many ways.

- **Table** - spreadsheet style.
- **Board** - Kanban columns grouped by a Select or Status property.
- **Calendar** - items placed on dates.
- **Gallery** - cards with cover images.

Use **Filter** to show only some rows (for example *Status is not Done*) and **Sort** to order them (for example by due date). Filters and sorts are saved per view.
