# Pages and blocks

Everything in Notion is a block: a paragraph, heading, checkbox, image, table or embedded file.

## Add and change blocks

- Type `/` on an empty line to open the block menu.
- Drag the `⋮⋮` handle to reorder blocks.
- Use `#`, `##`, `###` followed by a space for headings.
- Use `[]` for a to-do checkbox.

## Nested pages

Type `/page` to create a page inside a page. The sidebar shows the resulting tree, which is how you keep a workspace organised.
