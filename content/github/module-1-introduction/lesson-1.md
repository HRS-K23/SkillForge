# What is GitHub?

**Git** is a version control system that tracks changes to files on your computer. **GitHub** is a website that hosts Git repositories online so you can back up your work and collaborate with other people.

## Why people use it

- Keep a full history of every change to a project.
- Work on the same code as a team without overwriting each other.
- Review changes before they are merged (pull requests).
- Track bugs and ideas with issues.

## Key words

| Term | Meaning |
| --- | --- |
| Repository | A project folder plus its complete history |
| Commit | A saved snapshot of your changes |
| Branch | An independent line of development |
| Pull request | A proposal to merge one branch into another |
