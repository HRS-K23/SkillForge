# Creating a repository

1. Click the **+** icon at the top right and choose **New repository**.
2. Enter a name, for example `practice-project`.
3. Choose **Public** (anyone can see it) or **Private** (only you and people you invite).
4. Tick **Add a README file** so the repository starts with a description.
5. Click **Create repository**.

## The README

The `README.md` file is shown on the repository home page. Use it to explain what the project does and how to run it. It is written in Markdown.

## Good names

Use short, lowercase names with hyphens: `weather-app`, `portfolio-site`.
